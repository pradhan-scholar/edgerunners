🚀 Free Hosting Options
Option 1: GitHub Pages (Recommended — Completely Free)
Create a new GitHub repository (e.g., edgerunners)
Upload index.html to the repository
Go to Settings → Pages → Source → Deploy from branch → main
Your site will be live at https://yourusername.github.io/edgerunners
Option 2: Netlify (Free Tier)

✏️ Customization Guide
Replace Placeholder Content
About section: Update the bio text, stats numbers, and profile image
Discoveries: Replace with your actual research publications and breakthroughs
Projects: Update project names, descriptions, tech stacks, and progress bars
Contact: Replace your.email@example.com with your real email
Social links: Update all href="#" links in the footer
Add Your Profile Image

Replace the placeholder E.R. div in the About section with:

html
<img src="your-photo.jpg" alt="Profile" style="width:100%; height:100%; object-fit:cover;">
Customize Colors

Edit the CSS variables in :root at the top of the stylesheet:

css
--neon-red: #ff003c;    /* Primary accent */
--neon-cyan: #00f0ff;   /* Secondary accent */
--neon-yellow: #ffe600; /* Status color */
--neon-magenta: #ff00aa; /* Tertiary accent */
Add a Custom Domain

All free hosting providers above support custom domains. Point your domain's DNS to their servers and configure in the dashboard.
